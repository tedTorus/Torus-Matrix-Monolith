## 🛡️ The Arsenal

This monolith contains production-ready, highly advanced protocol architectures designed to solve the hardest problems in Web3:

### Zero-Knowledge & Privacy (`contracts/zk/`)
* **ZK Proof of Solvency**: A trustless audit layer for CEXs using Merkle Sum Trees and zk-SNARKs, proving reserves exceed liabilities without leaking user data.

### Decentralized Identity (`contracts/identity/`)
* **ZK-DID Selective Disclosure**: Privacy-preserving identity verification (e.g., proving age > 18) without revealing raw credentials, inspired by Polygon ID.
* **ERC-6900 Modular Smart Accounts**: A plugin-based operating system for Account Abstraction wallets.

### Infrastructure & Governance (`contracts/infrastructure/`)
* **MACI ZK-Voting**: Minimal Anti-Collusion Infrastructure to mathematically eliminate bribery in DAO governance.
* **EIP-4844 Blob Archival**: A decentralized storage network using KZG commitments to guarantee permanent availability of Ethereum L2 blobs.
* **Decentralized RPC Network**: A trustless API gateway with fraud proofs to slash malicious nodes.
* **zk-TLS Data Provenance**: Trustless ingestion of Web2 HTTPS data (via AES-GCM decryption circuits) into smart contracts.

### DeFi & Liquidity (`contracts/defi/`)
* **ZK Credit Scoring**: Enabling under-collateralized lending in DeFi through zero-knowledge off-chain credit proofs.
* **Intent-Based Cross-Chain Bridge**: Zero-slippage, instant cross-chain liquidity routing via relayer intents.
